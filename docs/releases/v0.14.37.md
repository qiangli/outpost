# Outpost v0.14.37

Release candidate notes, 2026-09-08. Changes since v0.14.36.

Outpost v0.14.37 pairs with Bashy v0.22.0. Hosts without an explicit
`bashy_version` pin reconcile their managed Bashy installation to v0.22.0
after Outpost upgrades and restarts. Explicit version pins remain supported.

This candidate refreshes the pinned shell and coreutils dependencies:

- sh: `749093a8f42748ab086a61e08002170ef0eefae8`
- coreutils: `66a54935c5e9b74f9aa1a5a5365a04e6c8f2bf65`
